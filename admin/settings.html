Facebook Pixel (iklan)

Ukur hasil iklan Facebook dan Instagram. Pixel dimuatkan pada halaman pembida sahaja, bukan halaman admin.

10 hingga 20 digit, daripada Meta Events Manager. Kosongkan untuk mematikan Pixel.

Perubahan Pixel ID berkuat kuasa selepas anda simpan.

Event yang dihantar
EventBila dihantar
Cara uji
  1. Pasang sambungan Chrome Meta Pixel Helper, atau buka Events Manager > Test events.
  2. Simpan Pixel ID, kemudian buka halaman kedai.
  3. Event PageView patut muncul dalam beberapa saat. Konsol pelayar juga mencatat setiap event sebagai [pixel].
